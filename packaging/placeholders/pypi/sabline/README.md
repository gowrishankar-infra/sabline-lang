# sabline

The Sabline language is published on PyPI as
[sabline-lang](https://pypi.org/project/sabline-lang/). This package holds
the name `sabline`, so that nothing else is published under it, and
installing it installs sabline-lang:

    pip install sabline          # installs sabline-lang

It has no code of its own. Source, documentation and signed releases are at
https://github.com/gowrishankar-infra/sabline-lang.
