# sabline

The Sabline language is published on npm as
[sabline-lang](https://www.npmjs.com/package/sabline-lang). This package
holds the name `sabline`, so that nothing else is published under it.
Installing it installs sabline-lang, and importing it gives sabline-lang's
exports:

    npm install sabline-lang      # what to install
    npx sabline-lang script.vel   # the command is sabline-lang's

It has no code of its own. Source, documentation and signed releases are at
https://github.com/gowrishankar-infra/sabline-lang.
