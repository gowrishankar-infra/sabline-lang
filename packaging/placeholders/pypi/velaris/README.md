# velaris

The Velaris language is published on PyPI as
[velaris-lang](https://pypi.org/project/velaris-lang/). This package holds
the name `velaris`, so that nothing else is published under it, and
installing it installs velaris-lang:

    pip install velaris          # installs velaris-lang

It has no code of its own. Source, documentation and signed releases are at
https://github.com/gowrishankar-infra/velaris-lang.
