# Findability kit: drafts, for a person to post

Everything here is a draft. Nothing in this directory is published, and
nothing here has been posted, submitted or sent: the maintainer posts,
submits and replies to all of it, by hand. Written 2026-09-25 with the
findability work in 8.7 (`plan/findability-research/` holds the research
each draft draws on).

The rules every draft follows, and every post should:

- **Say you made it.** Every venue here is one where the author posting
  their own project is allowed, and every one expects it said.
- **No asking for votes, stars or comments**, from anyone, anywhere. Hacker
  News bans accounts for it; the others only notice.
- **Limits first.** Each draft carries the project's own caveats: not a
  security boundary by itself, operating-system confinement full on Linux
  only, and it bounds programs written in Sabline and nothing else.
- **A venue's rules beat this kit.** Two venues forbid text a model wrote:
  Hacker News ("Don't post generated text or AI-edited text") and several
  conferences (Black Hat, RSAC, the CNCF events). For those this kit gives
  facts and a checklist, not text to paste - see each file.
