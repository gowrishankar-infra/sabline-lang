Competitors: the evidence, part 3

Categories 17 to 20 of the competitor table (the rest are in part 1, part 2), measured 2026-09-23: every cell's verdict, whether the program's legitimate work still succeeded where the row checks it, and the evidence line the harness wrote from what ran. The commands each cell ran, the input it was given and what it printed are in results.json, with the scratch directory written as <workdir> and the two listener ports as <port> (granted) and <other-port> (not).
