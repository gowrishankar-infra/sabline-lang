# velaris

The Velaris language is published on npm as
[velaris-lang](https://www.npmjs.com/package/velaris-lang). This package
holds the name `velaris`, so that nothing else is published under it.
Installing it installs velaris-lang, and importing it gives velaris-lang's
exports:

    npm install velaris-lang      # what to install
    npx velaris-lang script.vel   # the command is velaris-lang's

It has no code of its own. Source, documentation and signed releases are at
https://github.com/gowrishankar-infra/velaris-lang.
